
#  SoulEngine > Просто тренировка формирования деревьев объектов, в которую случайно залетел хак последнего бита.

# Интересная фишка
Когда собирал дерево, стало скучно писать обычный код, и я ради фана решил попробовать (хак младшего бита указателя). 
Суть простая: указатели на структуры в памяти выравниваются по 8 байт, поэтому последние биты в адресе всегда нулевые. Я забрал самый последний бит под флаг автооживления узла. Если там прилетает единица — код понимает, что это «виртуальный» узел, скидывает бит обратно в ноль и на лету выделяет память.
