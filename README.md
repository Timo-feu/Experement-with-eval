#  Evaluator (Eval)
![Complexity](https://img.shields.io/badge/Complexity-O%281%29-blue.svg)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT) 

**Eval** — это высокопроизводительная библиотека для оценки (evaluation) моделей и данных, спроектированная для работы с экстремально низкими задержками. В отличие от стандартных решений, наша версия поддерживает **все типы входных данных** без потери производительности, обеспечивая константное время выполнения.

## ✨ Ключевые особенности

- Полная поддержка всех типов данных (Integer, Float, String, Tensor, Custom Objects) "из коробки".
- Архитектура спроектирована так, чтобы абстракции не добавляли накладных расходов.
- Достижение задержки в **20 нс** на одну операцию оценки.
- Минимальное использование кучи (heap) и оптимизация кэша процессора.

## 🏗 Архитектура Pipeline

Процесс обработки данных в EvaEval оптимизирован для минимизации промахов кэша (cache misses) и исключения ветвлений (branch prediction optimization).


```
      [ Исходная строка ] ---> "x + sq(y)"
              |
              v
     ( In-place Токенизатор ) ---> [ Пропуск пробелов / Выделение токена ]
              |
              v
       [ Анализ типа ]
        /           \
   [Число]      [Идентификатор]

      |                |
Вычисление     Fast-Hash (FNV-1a)
значения               |
      |         ( Поиск в контексте )
      |          /                \
      |    [Переменная]       [Функция f(x)]

      |         |                   |
      |    Взять double       Рекурсивный парсер аргумента
      \         |                   /
       v        v                  v
   [  Немедленный расчёт подвыражения  ]
                |
                v
       [ Финальный double ]
```

## 📊 Бенчмарки и производительность
### График задержки (Latency Profile)

В наших тестах кривая задержки остается практически плоской независимо от сложности типа данных, что подтверждает нашу эффективность O(1)O(1) для операций доступа и базовой оценки.

> **Результат:** Мы достигли порога в **20 наносекунд**, что делает Eval идеальным инструментом для real-time систем, где каждая наносекунда на счету.

## 🚀 Быстрый старт
```
#include "Eval.h"

int main() {
    // 1. Регистрируем переменные и функции с compile-time хэшированием имён
    Object objs[3];
    objs[0] = { hash_const("x", 1), 50.0, nullptr };
    objs[1] = { hash_const("y", 1), 25.0, nullptr };
    objs[2] = { hash_const("sq", 2), 0.0, sq }; // sq — указатель на функцию double(double)

    Context ctx = { objs, 3 };

    // 2. Вычисляем выражение в реальном времени
    const char* expression = "x + y";
    double result = Eval::evaluate(expression, ctx);

    printf("Результат: %f\n", result); // Выведет 75.0
    return 0;
}
```

## 🛠 Технологический стек

- **Core:** Low-level memory management.
- **Optimization:** SIMD / AVX-512 instructions.
- **Dispatching:** Static polymorphism & Type erasure.
